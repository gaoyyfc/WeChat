# 贴图标题

下班后最累的，不是做饭，是每天重新想吃什么

# 内容介绍

站在冰箱前才开始想晚饭，往往比动手还耗神。这组 5 张贴图给下班后的晚饭分成“很累、平常、有余力”三种场景，每种只留两个备选，把每天重想一次改成少量可复用的选择。

# 发布正文

有些晚上并不是不想吃饭，而是下班后脑子已经用完了。打开冰箱，先要决定做什么，再看缺什么、怎么搭配，最后才轮到动手。

可以提前给家里的晚饭留三种情形：很累时做最省事的一顿，平常时做熟悉的一顿，有余力时再试新菜。每种只记两个家里人愿意吃的备选，买菜时补缺的主食、蛋白质和蔬菜就好。

不用把每天的晚饭都做成新题目。你家最常用来救急的一顿是什么？
