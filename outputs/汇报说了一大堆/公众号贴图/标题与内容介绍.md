# 贴图标题

汇报说了一大堆，领导还是问“所以呢”？

# 内容介绍

一条工作消息写得很长，领导却还要追问“所以需要我决定什么？”这组 6 张贴图用一个方案报价尚未复核的假设情境，演示怎样把进度、猜测和动作拆开，按“已确认的事实、自己的判断、需要对方决定的事”说清楚。最后一页可以留作下次汇报前的提醒。

# 发布正文

有时不是你没做事，也不是你没把过程讲完。你说了跟进多久、哪里还没处理好、接下来打算再沟通，对方听完却仍不知道：这件事现在需要我决定什么？

比如客户约明天看方案，报价还在复核。比起说“客户可能着急，我再沟通”，不如先交代已经确认的情况，再说明今晚硬发完整版可能出错，最后提出建议：先告知客户进度，等报价核对好再定发送时间，可以吗？

汇报前，先想清楚你希望对方回答哪一个问题。再挑出支持这个决定的事实，把不确定的地方明确说成判断。消息未必更长，却更容易得到回应。

你写工作汇报时，更容易卡在“说清事实”，还是“提出请求”？

# 逐页文字

1. 封面：汇报说了一大堆，领导还是问“所以呢”？
2. 问题：一段看似认真、却混合进度、猜测和动作的汇报。
3. 事实：客户约明天看方案；报价还在复核。“客户可能着急”仍是猜测。
4. 判断：今晚发完整版，报价可能出错；先说明进度是可考虑的处理方式。
5. 请求：建议先告知进度，确认报价后再定发送时间。可以吗？
6. 带走：已确认了什么？我判断会怎样？需要对方决定什么？
