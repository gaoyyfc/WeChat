# 正文图2新版：轻柔的三问方法卡

Use case: infographic-diagram  
Asset type: 微信公众号正文中的信息辅助图，不是海报、PPT或课程讲义  
Primary request: 重新设计一张轻、柔和、成熟的正文方法卡。它应当像生活方式杂志文章里自然出现的一页小笔记，与前两张自然光生活摄影协调，而不是一张大声喊话的展示板。

LAYOUT:
- 横版4:3，完全不透明的奶油白底，带极轻微、真实而细腻的纸张纹理。
- 整体内容占画面约65%，四周保留充足而不空洞的留白。
- 左上角放一行小号、细字重的引导语，不居中，不做主视觉。
- 中下部采用三条纵向排列的轻列表；每条是一块没有硬边框的浅色纸条或极淡色面，圆角轻微，间距宽松。
- 每条左侧只有一个小尺寸线性图标，右侧放中等字号问题。禁止巨型图标、巨型标题、三栏分割线和满版排字。
- 三条内容可有非常轻微的自然错位或纸片层次，但要克制、整齐、适合截图保存。

ZONES / LABELS（必须逐字准确）:
- 左上小引导语：“买之前，先问问自己”
- 第一条：“买得起吗？”；小图标为钱包或简洁账单。
- 第二条：“真喜欢吗？”；小图标为爱心与小放大镜。
- 第三条：“值得取舍吗？”；小图标为简洁天平或二选一符号。

TEXT (VERBATIM):
- “买之前，先问问自己”
- “买得起吗？”
- “真喜欢吗？”
- “值得取舍吗？”
- 只允许出现以上四句中文。不得添加序号、说明文字、英文、拼音、Logo、水印或其他字符。
- 中文使用清晰、端正、温和的现代中文黑体；字重常规或中等，不使用粗黑、艺术字、书法字和手写体。
- 引导语字号约为问题文字的55%—60%；三个问题使用中等字号，不占满卡片。

COLORS:
- 背景：奶油白 #F8F3EB，完全不透明。
- 第一条浅暖陶色面，图标暖陶棕 #AC735C。
- 第二条极浅鼠尾草绿色面，图标鼠尾草绿 #829480。
- 第三条浅暖灰色面，图标深咖灰 #39352F。
- 所有文字统一深咖灰 #39352F；整体低饱和，色差柔和。
- 色值和颜色名仅用于渲染指导，绝对不要显示在画面中。

STYLE / MATERIAL:
- soft editorial method card，成熟的中国女性生活方式公众号视觉。
- 纸张质感细腻，像印在自然纸上的一页内容卡；有极轻柔的自然光感，但不是桌面实拍，也不要出现手、咖啡杯、植物等额外道具。
- 线条细、图标小、字不喊话、留白舒展；整体温和、克制、会聊天。

AVOID:
- PPT、课程讲义、宣传海报、课堂板书、企业培训图、营销信息流广告。
- 大号居中标题、超粗黑体、三栏硬分割、巨型图标、直角粗边框、强对比。
- 卡通、手账、涂鸦、可爱风、儿童课件、渐变、霓虹色、强阴影、立体按钮。
- 透明背景、黑底、颗粒喷溅、荧光色、乱码、错别字、漏字、重复字、伪中文。

ASPECT: 4:3 landscape. Opaque background. Low visual density, generous refined whitespace, excellent mobile legibility.
