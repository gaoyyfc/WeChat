# 项目文件说明

- `backups/`：正文初稿、精修稿和旧版 WeMD 文件。
- `images/final/`：当前正式使用的封面、静物图和竖版方法卡。
- `images/archive/`：未采用或已被替换的图片版本。
- `generation/method-card/`：方法卡的 SVG 源文件与渲染脚本。
- `prompts/`：三张图片的提示词和生成说明。
- `notes/`：文章大纲与版式预览记录。

当前可发布文章位于工作区根目录：

`02-给自己买件喜欢的东西-为什么还要证明它很实用.md`

发布稿使用 WeMD 官方图床链接，以保证 WeMD 预览和复制到微信公众号时能正常显示图片。本目录中的最终图片仍保留为本地备份。
