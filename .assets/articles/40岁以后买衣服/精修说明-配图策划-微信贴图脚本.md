# 《40岁以后买衣服，别只看价格，这4个细节更值得看》制作说明

## 修改前后差异

1. 开头仍保留“换季打折、买回家后不合适”的场景，但改为普遍生活情境，不使用第一人称，也不暗示这是一件经过真实测评的商品。
2. 面料部分拆分为两层：短时间试穿只能初步感受粗糙、发扎、明显闷热、透与不透、里衬是否舒服；缩水、掉色、起球和静电明确写为不能靠短时间试穿确定。
3. 护理部分改为查看成分标签和洗护说明，只据此判断清洗、晾晒、熨烫与专业洗护要求，不推断长期穿洗结果。
4. 面料、版型、护理、搭配四个核心标准全部保留，没有增加第五项标准。
5. 原来的“三句话快速检查”改为“付款前，再花30秒”，落实为“动一动、翻一翻、想一想”三个动作。
6. 删除“有两句答不上来就先不买”的机械门槛，让购买决定回到预算、舒适度和个人生活需要。
7. 保留评论区问题，并增加“烟火有主意”品牌落款。
8. 正文增加三处图片占位，封面仍独立使用。

## 四张图片策划

当前确认安装并适合本任务的宝玉 Skill 是 `baoyu-article-illustrator`。未确认安装独立的 `baoyu-cover-image` 或 `baoyu-infographic`，因此不虚构使用；后续可在该 Skill 内分别使用 `scene` 和 `infographic` 类型。当前保存偏好为 `sketch-notes`，但本篇明确要求写实摄影感，后续生成时应以本次要求覆盖该偏好。

### 1. 封面图｜试衣间里的认真判断

- **对应 Skill**：`baoyu-article-illustrator`
- **推荐类型**：`scene`
- **位置**：公众号封面，正文外独立使用。
- **比例**：2.35:1 横版；人物和试衣动作放在中央安全区域，同时预留一侧标题空间。
- **画面**：一位约40—50岁的中国城市女性，在普通、整洁的服装店试衣镜前试穿一件日常上衣或薄外套。她轻触衣领或抬手查看活动度，表情认真自然，不是兴奋抢购。
- **写实要求**：真实生活摄影感，自然商场光线，正常皮肤纹理，衣物褶皱合理；不做网红脸、奢侈品广告、淘宝模特姿势或夸张磨皮。
- **色彩**：奶油白、暖陶棕、鼠尾草绿、深咖灰，低饱和。

### 2. 正文图1｜面料与服装细节

- **对应 Skill**：`baoyu-article-illustrator`
- **推荐类型**：`scene`
- **插入位置**：正文占位 `[正文配图1｜面料与服装细节图]`，位于面料部分之后。
- **比例**：4:3 横版。
- **画面**：服装店或家中窗边的衣物细节近景。一只自然的成年女性手轻轻翻看衣领、袖口、里衬和成分洗护标签；重点表现织物纹理、缝线和标签，不出现可识别品牌。
- **必要性**：帮助读者直观看到“手感检查”和“查看标签”是两件不同的事。
- **写实要求**：微距生活摄影，自然手部结构，标签可保持无字或仅有不可识别符号，避免AI乱码；不能暗示仅凭画面已经完成缩水、掉色或起球测试。

### 3. 正文图2｜现有衣柜的搭配

- **对应 Skill**：`baoyu-article-illustrator`
- **推荐类型**：`scene`
- **插入位置**：正文占位 `[正文配图2｜日常衣物搭配示意图]`，位于搭配部分中段。
- **比例**：4:3 横版。
- **画面**：一件待考虑的上衣与家中已有的两组日常搭配自然摆放：长裤、半身裙、平底鞋或轻便外套。像真实衣柜整理过程，不做电商平铺展示。
- **必要性**：把“至少想出两套现成搭配”变成一眼能理解的方法。
- **写实要求**：中国城市家庭卧室或衣帽区，自然光，衣物有真实使用痕迹和柔软褶皱；不出现大量新品、奢侈品牌或不符合日常生活的精致陈列。

### 4. 正文图3｜30秒购前检查卡

- **对应 Skill**：`baoyu-article-illustrator`
- **推荐类型**：`infographic`
- **插入位置**：正文占位 `[正文配图3｜30秒购前检查卡]`，位于“付款前，再花30秒”开场之后。
- **比例**：3:4 竖版，优先手机阅读。
- **画面结构**：奶油白纸张质感，分成三个轻量区域，准确呈现：
  - 动一动｜坐下、抬手、走两步
  - 翻一翻｜检查成分与洗护说明
  - 想一想｜衣柜里有没有现成搭配
- **必要性**：方便读者截图保存，也承担正文方法的视觉总结。
- **视觉要求**：不是PPT或课程板书；标题克制，说明文字可直接在手机上阅读。使用暖陶棕、鼠尾草绿和深咖灰，配极简动作、标签、衣架图标。中文必须准确，如生成文字不稳定，应重新生成，不保留乱码版本。

## 5张微信贴图脚本

### 第1张｜钩子

**标题**  
打折买回来的衣服，为什么反而最容易闲置？

**主文案**  
买的时候觉得捡了便宜，  
回家后才发现——  
穿着不舒服，不好打理，  
也找不到现成的衣服搭。

最后，它只是挂在衣柜里。

**作用**  
钩子。用“便宜但闲置”的反差吸引读者继续看。

**配图建议**  
中国40—50岁女性站在服装店衣架前查看价签，神情认真而非兴奋；普通城市商场，自然抓拍感，画面保留文字区域。

### 第2张｜共鸣场景

**标题**  
衣服真正的成本，不只写在吊牌上

**主文案**  
领口扎，穿半天就想脱；  
版型紧，坐下来不自在；  
洗过几次就懒得再穿；  
为了搭它还要再买裤子和鞋。

这些麻烦，也算在衣服的价格里。

**作用**  
共鸣。把“买回家才发现的问题”具体说出来，让读者想到自己的衣柜。

**配图建议**  
家中衣柜一角，一件几乎没穿过的衣服挂在里面，旁边是经常穿的基础款；环境整洁真实，不刻意制造凌乱。

### 第3张｜方法点1

**标题**  
试衣服，别只站着照镜子

**主文案**  
**看面料：**  
领口、袖口贴着皮肤时舒不舒服？  
浅色衣服会不会明显透？

**看版型：**  
坐下、抬手、走几步。  
腰腹会不会勒？衣摆会不会往上跑？

**舒服，比“看起来显瘦”更重要。**

**作用**  
方法。提供在试衣间里立刻可以执行的检查动作。

**配图建议**  
中国成熟女性在普通试衣间自然抬手或坐下测试衣服活动度；穿着日常得体，重点表现真实动作和衣服状态。

### 第4张｜方法点2

**标题**  
付款前，再看两个地方

**主文案**  
**看看洗涤说明：**  
能不能机洗？需不需要熨烫、送洗？

**想想自己的衣柜：**  
现在有没有裤子、鞋和外套能搭它？

不好打理，又要继续添置，  
再低的折扣也未必划算。

**作用**  
方法。把护理成本和搭配成本合并成简单、实用的购买检查。

**配图建议**  
左右分区的生活化画面：一侧是衣服洗涤标签，另一侧是衣柜中颜色协调的几件衣服；也可制作克制的信息卡，避免电商展示感。

### 第5张｜总结与账号定位

**标题**  
值不值，看它回家以后

**主文案**  
一件值得买的衣服，  
不一定是折扣最大的一件，  
而是穿着舒服、容易打理，  
也能真正进入日常生活的一件。

**烟火有主意**  
不劝你盲目多买，也不劝你一味委屈。  
聊一点悦己生活，分享一点实用经验，  
一起把钱花明白，把日子过舒服。

**作用**  
总结并建立账号认知。让读者明白关注后能持续获得理性消费和生活经验内容。

**配图建议**  
中国40—50岁女性穿着简洁舒适的日常服装走在城市街道、展馆或咖啡店附近，状态自然从容；画面留出品牌落款区域，避免广告大片感。
