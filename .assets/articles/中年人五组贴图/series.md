# 五组贴图逐页文字

每组 5 张，均为 3:4 竖版；封面先生成，再以封面统一内页风格。暖纸底、黑色手绘线条，薄荷绿、珊瑚色、浅蓝点缀。文字优先，画面为具体生活物件，不画不必要的人像。场景为原创的概括性示例。

## 01 工作之外
1. 40岁以后，日子不能只剩上班 / 留一点只属于自己的期待
2. 一周都很忙 / 上班、家务、刷手机 / 忙完却想不起哪件事是为自己做的
3. 别急着安排大事 / 走一条没走过的路、读几页想读的书、约一个愿意见的人
4. 把一件小事写进日历 / 先留半小时 / 不用等所有事做完
5. 工作很重要 / 但你也需要工作之外的生活 / 下周想留给自己哪半小时？

## 02 接活边界
1. 人到中年，最累的不是忙 / 是每件事都说“我来”
2. 同事临时求助、领导新增任务、家里又有安排 / 时间没变，待办却一直加
3. 接下之前先问：什么时候要？我手上哪件事要后移？一定得由我做吗？
4. 可照着说：我能接这件事，但手上的 A 要延到周四。您希望先保哪一项？
5. 说清代价，不等于不负责 / 好的答复，也包括说清自己做得到什么

## 03 睡前脑子停不下
1. 躺下了，脑子还在开会 / 明明很累，却开始想明天
2. 想起没回的消息、担心明天的事、又拿起手机 / 越想快睡，越清醒
3. 睡前写下：明天最先处理什么、什么时候处理 / 今晚不用把它解决
4. 给睡前留一段缓冲 / 放下屏幕，做安静的事；房间尽量暗、静
5. 今晚先休息，不必解决所有问题 / 若睡不好持续影响白天，请咨询医生

## 04 孩子成绩
1. 孩子成绩一般，父母先别急着给结论 / 一次分数，不是全部答案
2. 成绩出来，最容易先问：怎么又考成这样？ / 孩子可能只剩下辩解和沉默
3. 换成三个具体问题：哪一部分最难？你试过什么？需要我帮什么？
4. 学业要面对，孩子会坚持的事也值得看见 / 一起选一个能做的小步骤
5. 少一次“你怎么不努力” / 多一次一起找办法 / 不用一次谈话解决所有问题

## 05 下班晚饭
1. 下班后最累的，不是做饭 / 是每天重新想吃什么
2. 站在冰箱前，脑子已经用完 / 想吃得像样，又不想再做一道选择题
3. 先定三种晚饭：很累的一顿、平常的一顿、有余力的一顿
4. 每种只留两个备选 / 主食、蛋白质、蔬菜提前想好 / 买菜时只补缺的
5. 晚饭不用天天出新题 / 少一道决定，回家就轻松一点
